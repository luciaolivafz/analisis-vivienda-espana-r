# Datos

Esta carpeta contiene los archivos CSV utilizados en el proyecto.

**Archivo no incluido:** `poblacion_2020_2024.csv`, debido a que supera el límite de tamaño permitido por GitHub.

Para descargarlo, accede a la [tabla 56945 del Instituto Nacional de Estadística (INE)](https://www.ine.es/jaxiT3/Tabla.htm?t=56945) y selecciona las siguientes categorías:

- **Edad simple:** Todas las edades.
- **Provincias:** Seleccionar todas las opciones (incluido Total Nacional).
- **Sexo:** Total, Hombres y Mujeres.
- **Periodo:** Seleccionar todos los periodos desde el 1 de enero de 2020 hasta el 1 de octubre de 2024, ambos incluidos.

Una vez seleccionadas las categorías, pulsa **Consultar selección** y descarga los datos en formato CSV. Guarda el archivo en esta carpeta con el nombre `poblacion_2020_2024.csv`.
